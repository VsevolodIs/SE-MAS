# math_solver — символьное решение математической задачи

## Назначение
Для ученика 5–9 класса решать уравнения и простые алгебраические выражения.

## Инструмент
`src.tools.sandbox.run_sandboxed_math` вычисляет символьные корни в отдельном рабочем процессе.
Результат инструмента является источником числовых значений; LLM оформляет шаги объяснения.

## Ограничения
- Не объявлять вычисление подтверждённым, если инструмент вернул `unsupported_format`, `timeout_error` или `math_error`.
- Учитывать область допустимых значений и действительную область поиска.
- Не подменять условие задачи другим уравнением.
- Для задач не в формализованном виде явно отмечать, что SymPy не проверил решение.
